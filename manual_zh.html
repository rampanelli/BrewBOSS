BrewBOSS

一款带有Web界面和LCD/键盘独立操作的酿造自动化控制器。本指南逐步说明如何安全地操作该系统。

1. 概述

BrewBOSS是一款电动酿造设备控制器。它管理加热器、泵和整个酿造日的计时器，并实时报告温度和进度。

支持：加入BeerSchool论坛上的BrewBOSS官方社区 — 分享您的设备、提问并帮助其他酿酒师。

您可以通过三种方式操作，它们可以协同工作：

  • Web界面 — 设备提供的单页面；从浏览器控制一切。
  • LCD和4个按钮 — 完全独立操作，即使没有网络。
  • REST API — 可选，用于集成和脚本。

功能：

  • 运行可编程糖化步骤、带定时酒花添加的自动煮沸，以及带温度触发添加和最终冷却的后煮沸阶段。
  • 以完全手动（直接功率）或预编程配方方式运行。
  • 管理配方（创建、编辑、保存、激活、删除）和导入配方 — 兼容BeerSmith / Brewfather等工具，您自己的配方也可以导出和导入。
  • 记录日志：温度CSV（每分钟一个样本，含事件）可用于详细的糖化图表，为您的特定设备微调配方的。
  • 断电后自动恢复，从中断处继续酿造。
  • 通过安全系统（过温切断和传感器丢失切断）保护批次。
  • 在线或离线工作；在20×4 LCD上显示状态。
硬件兼容性它运行在ESP8266 (Wemos)、ESP32和ESP32-C3开发板上，与BrewManiac和BrewUNO等其他项目使用的接线100%兼容 — 只需刷写即可使用。

2. 前提条件与安装

操作BrewBOSS需要：

  • 一块已安装BrewBOSS固件的支持控制器板（Wemos/ESP8266、ESP32或ESP32-C3）。
  • 连接的酿造硬件：通过SSR连接的加热器、一个泵，以及一个或多个DS18B20温度传感器。可选的20×4 I²C LCD和4个按钮可实现独立使用。
  • 一部带有Web浏览器的手机、平板或电脑。
  • 可选的家用Wi‑Fi网络（否则设备会创建自己的接入点）。

安装固件（刷写）

如果开发板尚未刷写，请使用esptool写入固件和文件系统：

  1. 从binaries文件夹下载适用于您开发板的两个.bin文件：固件（无_fs后缀 — 首先刷写）和文件系统（_fs后缀 — 然后刷写）。
  2. 在正确的偏移地址刷写 — 以Wemos/ESP8266为例（将<version>替换为下载的版本）：
esptool.py --chip esp8266 --port COMx write_flash 0x0 BrewBOSS_<version>_esp12e.bin
esptool.py --chip esp8266 --port COMx write_flash 0x200000 BrewBOSS_<version>_esp12e_fs.bin
完整刷写指南ESP32 / ESP32-C3的二进制文件、精确偏移地址和命令可在项目帮助页面找到。ESP8266固件已包含其引导程序，因此写入地址0x0。

3. 访问系统

  1. 给控制器通电。启动时它会初始化文件系统、Wi‑Fi、传感器、LCD和键盘。
  2. 连接到它的接入点。默认情况下，设备创建一个名为BrewBOSS的Wi‑Fi网络（密码brewboss），IP为192.168.4.1。
  3. 用您的手机/PC加入该网络，在浏览器中打开http://192.168.4.1。
  4. 如果登录已启用（设置 → 系统 → 安全），会弹出登录窗口。否则，界面将以完全访问权限打开。

登录与访问级别

访问保护是可选的，默认禁用（无需登录）。要启用它，请前往设置 → 系统 → 安全，打开开关，设置密码并保存。启用后，默认密码为brewboss。

  • 输入正确密码 → 登录：完全访问。会话持续到设备重启。
  • 忽略：只读访问 — 您可以查看所有内容但无法进行更改。
  • 密码错误：再次询问，最多10次尝试，然后降级为只读。

您可以在设置 → 系统 → 安全中更改或删除密码。空密码将完全禁用登录。

忘记密码？重新刷写文件系统会将其重置为brewboss。

切换到您的Wi‑Fi

要将控制器连接到家庭网络，请打开设置 → 系统 → WiFi，选择模式并输入SSID/密码，然后保存并重启。

Wi‑Fi模式AP = 设备是自己的网络（离线使用）。STATION = 仅连接到您的路由器。MIXED = 两者同时。在STATION模式下，如果60秒内无法连接，则回退到接入点。

4. 界面导航

界面左侧有一个侧边菜单，顶部有一个状态栏。

侧边菜单 — 主要目的地：

  • 仪表盘 — 显示实时温度、计时器和控制按钮的主屏幕。
  • 配方 — 您的配方库以及糖化/煮沸步骤编辑器。
  • 设置 — 调整、系统（网络、安全、时间、备份）和关于。
  • 模式 — 切换界面的颜色主题。
  • 关于 — 版本和硬件信息。

点击状态栏可折叠/展开菜单（在手机上很有用）。

状态栏 — Wi‑Fi指示器、NTP（时钟）点、HEAP（空闲内存）点和设备运行时间。

5. 逐步操作

以下是使用配方进行酿造日的典型流程：

  1. 准备。填满煮沸锅，放置传感器，连接到界面。
  2. 选择配方。打开配方，选择一个并激活。
  3. 检查设置。在设置 → 调整中，确认温度单位、煮沸温度/时间和传感器。
  4. 开始糖化。在仪表盘上按Start。系统加热到第一步的目标温度，然后运行其计时器。
  5. 跟踪进度。观察仪表和步骤历史。当锁定的步骤发出蜂鸣声时，将其释放。
  6. 煮沸。最后一个糖化步骤后，系统自动进入煮沸。加热至沸腾，运行计时器并按时触发每个酒花添加。
  7. 后煮沸和冷却。加热关闭，监控冷却并触发基于温度的添加，然后执行最终冷却步骤。
  8. 完成。蜂鸣器发出结束信号，屏幕显示总酿造时间。
定时启动（延迟）您可以安排糖化或煮沸稍后开始。LCD显示倒计时，进程在归零时自动开始。

6. 各界面逐一说明

以下各部分说明屏幕名称、显示内容、用途以及如何操作。

6.1 — 仪表盘（主界面）

显示内容。带有三个圆形仪表和计时器卡片的主屏幕：主温度、洗糟温度、功率（PWM），以及带有当前步骤名称的酿造计时器。

用途。在这里启动、监控和停止酿造，并读取实时状态。

如何操作。使用仪表下方的控制按钮。在手动模式下，可以点击仪表设定目标温度或功率。

6.2 — 步骤与步骤历史

显示内容。当前步骤/计时器和每个过程里程碑的运行列表。

用途。精确跟踪酿造的位置和刚刚发生的事情。

如何操作。阅读以跟踪。事件类型用颜色编码。

6.3 — 配方

显示内容。您的配方库，带有搜索框和排序功能，以及导入按钮。

用途。创建、存储和重复使用配方。

如何操作。激活一个配方以加载用于酿造。导入保存在其他地方的配方；保存/编辑您自己的配方；删除不再需要的配方。

6.4 — 糖化步骤编辑器

显示内容。糖化步骤列表，包含名称、目标温度、时间和每个步骤的标志。

用途。定义糖化曲线。

如何操作。添加、编辑和重新排序步骤；设置温度和时间；设置标志：循环（运行泵）、加热器开启、全功率、步骤锁定（暂停以进行手动操作）。

6.5 — 煮沸与添加编辑器

显示内容。煮沸程序和添加。

用途。安排在煮沸期间和之后的酒花添加。

如何操作。添加并选择每个添加的触发方式：定时添加（煮沸期间）、后煮沸添加（按温度）或最终冷却。

6.6 — 调整

显示内容。适用于每个批次的酿造参数：单位、延迟、功率百分比、煮沸温度/时间、洗糟、PID带宽、泵时序、传感器分配和复选框。

用途。使控制器匹配您的设备。

如何操作。设定值并按保存。使用传感器偏移对照参考温度计校准读数。

6.7 — 系统（网络、安全、时间、备份）

显示内容。设备配置面板。

用途。网络、登录、时钟和备份。

如何操作。设置Wi‑Fi模式和凭据、安全（登录开关和密码）、NTP服务器和GMT偏移，以及备份（导出/导入配置）。

6.8 — 关于

显示内容。固件版本、硬件、网络状态、时间/NTP和系统信息。

用途。健康检查以及寻求帮助时需要包含的信息。

如何操作。只读 — 用于验证一切正常。

6.9 — 颜色主题（模式）

显示内容。不同配色方案下的界面。

用途。舒适度和可读性 — 例如为昏暗的酿造室提供深色主题。

如何操作。点击侧边菜单中的模式以循环切换可用的配色方案。

7. 按钮、字段、消息与指示器

控制按钮（仪表盘）

  • Start — 开始糖化。
  • Pause / Resume — 暂停和恢复。
  • Stop — 停止一切。
  • Skip — 跳过当前糖化步骤。
  • Boil — 直接开始煮沸。
  • Pump — 开关泵。
  • Prime — 运行自动引水循环。

状态指示器

  • Wi‑Fi：连接到网络时的信号强度（dBm），或者当设备作为接入点运行时显示AP（绿色）加接入点名称。
  • NTP点：时钟同步时为绿色。
  • HEAP点：空闲内存健康状态。
  • 运行时间：设备已运行的时间。

消息与事件

步骤历史和LCD显示诸如Brew STARTED、目标到达、步骤完成、酒花添加和完成等事件。带有警报的SAFETY事件表示保护功能被触发。

声音（蜂鸣器）

时机听到的声音
达到目标温度两声长鸣
糖化步骤推进短–短–长
开始煮沸 / 酒花添加两短 + 两长
步骤锁定（需要您的操作）每15秒两声鸣响
酿造完成四声长鸣

8. 操作模式

  • 糖化 — 运行您的糖化步骤；对每个步骤加热到目标，运行计时器，然后推进。最后一步后自动进入煮沸。
  • 煮沸 — 加热到煮沸温度，运行计时器并触发定时添加。可单独启动。
  • 后煮沸 — 加热关闭；监控冷却并触发基于温度的添加，然后执行最终冷却步骤。
  • 手动 — 您直接设定加热器功率（开环）。目标仅供参考。不保存用于恢复。
  • 延迟（定时启动） — 延迟启动糖化或煮沸；设备倒计时并自动开始。

泵与引水

  • 泵 — 手动开关；在循环步骤期间自动控制。
  • 引水 — 自动循环（5 × 3秒开 / 2秒关），在开始前填充管道。

9. 独立使用 — LCD与物理按钮

您可以在没有Web界面的情况下完成整个酿造过程。

20×4显示屏

[w] BrewBOSS 00:14:32         <- Wi-Fi图标 + 标题 + 步骤计时器
[H]  65.20>66   [W] 68% [P]   <- 主温度：当前>目标, 功率, PWM, 泵
[S]  74.00>74   100%        M <- 洗糟：当前>目标, PWM, 标志 B/M/L
Add Citra 30g@15'             <- 最后事件消息（或IP / AP）
  • 第1行 — Wi‑Fi图标 + "BrewBOSS"，酿造期间带步骤计时器；否则显示版本。
  • 第2行 — 主温度（当前>目标）、单位、加热器功率、PWM%以及泵开启时的泵图标。
  • 第3行 — 洗糟温度和其PWM%；标志：B（煮沸暂停）、M（糖化暂停）或L（步骤锁定）。
  • 第4行 — 最后事件消息；空闲时显示IP: <地址>或AP: 192.168.4.1。

酿造完成后，屏幕显示感谢信息15秒，然后显示总酿造时间，直到您按任意按钮。

4个按钮

四个薄膜键盘按钮编号为1–4。每个按钮响应三种按压时长：短按、长按（约2秒）和超长按（约3秒）。启动模式后有1.5秒锁定以防止意外停止。

按压1234
短按泵 开/关功率 −10%功率 +10%暂停 / 恢复
长按（约2秒）引水启动手动 / 跳过步骤 / 解锁启动煮沸启动糖化
超长按（约3秒）—停止停止停止
  • ±10%功率变化影响当前模式的活跃加热器。
  • 糖化中，长按按钮2跳过当前步骤；如果步骤被锁定，同样的长按会解锁并推进它。
  • 完成后的"总时间"屏幕上，任意按钮返回主屏幕。

10. 断电恢复

如果在酿造过程中断电，重启时设备会检测到保存的状态，进入暂停并在LCD上显示"已恢复！是否继续？"。

  1. 按按钮4（短按）从中断处恢复。
  2. 如果时钟已同步，剩余时间会根据设备关闭的时间进行调整。
注意手动模式不会被恢复（它没有保存的状态）。

11. 主要使用流程（快速参考）

  1. 通电 → 连接到BrewBOSS / 打开192.168.4.1 → 登录。
  2. 配方 → 激活您的配方。
  3. 调整 → 确认单位、温度和传感器。
  4. 仪表盘 → Prime（可选） → Start。
  5. 糖化运行并推进 → 进入煮沸 → 添加按时触发。
  6. 后煮沸 / 冷却 → 完成（显示总时间）。

12. 最佳实践

  • 首次酿造前，对照可靠温度计校准传感器偏移。
  • 在开始糖化前运行引水并确认流量。
  • 将设备保持在可信Wi‑Fi网络中 — 连接在本地网络上以明文传输密码。
  • 将您的酿造保存为配方，并使用温度日志/CSV为您的设备进行微调。
  • 完成设备配置后制作备份（导出）。
  • 保持加热器周围区域整洁；切勿让活跃的酿造完全无人看管。

14. 固件与安装

适用于3个支持控制器的固件（LittleFS单独提供）。文件系统映像为LittleFS格式。

文件和偏移地址

binaries文件夹中的每个版本都包含每个控制器两个文件：BrewBOSS_<version>_<board>.bin是固件（首先刷写），BrewBOSS_<version>_<board>_fs.bin是文件系统（LittleFS — 然后刷写）。以_fs结尾的文件总是文件系统；没有后缀的是固件。<board>为esp12e（Wemos D1 Mini / ESP8266）、esp32（ESP32 WROOM-32）或esp32c3（ESP32-C3 Super Mini）。

控制器文件类型偏移地址大小
Wemos ESP8266 (ESP12E)BrewBOSS_<version>_esp12e.bin固件0x00000000约440 KB
BrewBOSS_<version>_esp12e_fs.binLittleFS0x00200000约2,024 KB
ESP32 esp32devBrewBOSS_<version>_esp32.bin固件0x00010000约1,010 KB
BrewBOSS_<version>_esp32_fs.binLittleFS0x00290000约1,408 KB
ESP32-C3BrewBOSS_<version>_esp32c3.bin固件0x00010000约1,020 KB
BrewBOSS_<version>_esp32c3_fs.binLittleFS0x00290000约1,408 KB

OTA固件与文件系统更新

BrewBOSS支持通过Web界面直接进行无线 (OTA)更新。这消除了日常更新中对USB线和esptool的需求。先上传固件文件（无_fs后缀），然后上传文件系统文件（_fs后缀）。

  • 工作原理：在Web界面中访问设置 → 系统 → 固件更新。上传新的固件和文件系统二进制文件。设备处理向闪存的内部写入并重启。
  • 优势：
  • 安全性：引导程序包含自动回退功能，确保即使更新中断，设备仍能正常工作。
  • 效率：无需手动计算偏移地址，即可在固件版本和文件系统结构之间无缝过渡。

前提条件

  • 安装esptool：pip install esptool
  • 通过USB连接控制器并找到其串口（例如Windows上的COM5，Linux上的/dev/ttyUSB0）。
  • 从.bin文件所在的文件夹运行命令。
  • 将COMx替换为正确的端口。添加--baud 460800以获得更快的刷写速度。

刷写（更新）

对于已配置的控制器，首先刷写固件，然后刷写文件系统（_fs） — 两个独立的步骤（更可靠）。用下载的版本替换<version>：

Wemos / ESP8266 — 固件

esptool.py --chip esp8266 --port COMx --baud 460800 write_flash 0x0 BrewBOSS_<version>_esp12e.bin

Wemos / ESP8266 — 文件系统

esptool.py --chip esp8266 --port COMx --baud 460800 write_flash 0x200000 BrewBOSS_<version>_esp12e_fs.bin

ESP32 (esp32dev) — 固件

esptool.py --chip esp32 --port COMx --baud 460800 write_flash 0x10000 BrewBOSS_<version>_esp32.bin

ESP32 (esp32dev) — 文件系统

esptool.py --chip esp32 --port COMx --baud 460800 write_flash 0x290000 BrewBOSS_<version>_esp32_fs.bin

ESP32-C3 — 固件

esptool.py --chip esp32c3 --port COMx --baud 460800 write_flash 0x10000 BrewBOSS_<version>_esp32c3.bin

ESP32-C3 — 文件系统

esptool.py --chip esp32c3 --port COMx --baud 460800 write_flash 0x290000 BrewBOSS_<version>_esp32c3_fs.bin
ESP8266 固件已包含引导程序（eboot），因此写入地址0x0。2个文件就足够了。

空白芯片 / 首次刷写（ESP32 / ESP32-C3）

在执行erase_flash后或在全新芯片上，必须按正确偏移地址刷写全部5个文件。引导程序、分区表和boot_app0已包含在binaries文件夹中。

ESP32-C3 Super Mini - BOOT按钮对于首次刷写（引导程序位于0x0），必须在运行命令时按住开发板上的BOOT按钮。刷写开始后松开。后续刷写无需按钮即可运行。

1. 引导程序

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x0000 BrewBOSS_<version>_esp32c3_bootloader.bin

2. 分区表

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x8000 BrewBOSS_<version>_esp32c3_partitions.bin

3. 引导应用

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0xe000 BrewBOSS_<version>_esp32c3_boot_app0.bin

4. 固件

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x10000 BrewBOSS_<version>_esp32c3.bin

5. 文件系统

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x290000 BrewBOSS_<version>_esp32c3_fs.bin

仅更新固件（引导程序不变）

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x10000 BrewBOSS_<version>_esp32c3.bin

仅更新文件系统

esptool.py --chip esp32c3 --port <port> --baud 460800 write_flash 0x290000 BrewBOSS_<version>_esp32c3_fs.bin
先擦除全部（可选） esptool.py --chip <esp32|esp32c3|esp8266> --port COMx erase_flash。这也会擦除存储在LittleFS中的WiFi/配方配置。

注意事项

  • 偏移地址对当前分区表（4 MB闪存）有效。如果表更改，偏移地址也会更改。
  • 映像为LittleFS（非SPIFFS） — 固件将文件系统挂载为LittleFS。
  • 刷写后，控制器启动Web服务器；通过网络IP或AP访问。
  • 带原生USB的ESP32-C3：端口显示为Espressif串行设备（VID 303A）；刷写时的重置/启动是自动的。
