================================================================================
                       BREWBOSS WEB FLASHER - BINARIOS
================================================================================
                    SOMENTE USO PESSOAL - NAO COMERCIAL
================================================================================

Esta pasta (binaries/flasher) contem os binarios MERGEADOS (imagem unica)
prontos para gravacao pelo Web Flasher. Grave cada arquivo UMA unica vez no
endereco 0x000000 (a imagem ja contem todas as partes posicionadas nos offsets
corretos: bootloader, partitions, boot_app0/otadata, firmware e filesystem).

As partes SEPARADAS (bootloader, partitions, boot_app0, firmware, filesystem)
para gravacao manual ficam na pasta binarios (uma nivel acima), identificadas
por modelo, ex: BrewBOSS_v<ver>_esp32c3_bootloader.bin.

================================================================================
1. IMAGENS MERGEADAS (gravar em 0x000000, uma unica operacao)
================================================================================

  BrewBOSS_v2.2.26c_esp12e_full.bin   -> Wemos D1 Mini / ESP8266 (ESP12E)
  BrewBOSS_v2.2.26c_esp32c3_full.bin  -> ESP32-C3 Super Mini
  BrewBOSS_v2.2.26c_esp32c5_full.bin  -> ESP32-C5 MINI V1.0

  ESP12E  (ESP8266):  firmware (incl. bootloader) @ 0x000000
                      filesystem (LittleFS)        @ 0x200000
  ESP32-C3:           bootloader                    @ 0x000000
                      partitions                    @ 0x008000
                      boot_app0 / otadata           @ 0x00E000
                      firmware                      @ 0x010000
                      filesystem (LittleFS)         @ 0x290000
  ESP32-C5:           bootloader                    @ 0x002000
                      partitions                    @ 0x008000
                      boot_app0 / otadata           @ 0x00E000
                      firmware (factory image)      @ 0x010000
                      (sem filesystem: a UI e os configs padrao sao criados
                       no primeiro boot pelo proprio firmware)

  Observacoes:
  - A imagem mergeada ja inclui TODAS as partes; NAO grave outro binario por cima.
  - Apos gravar, o controlador reinicia sozinho no BrewBOSS.
  - C5: interface web embutida no firmware; configs criados automaticamente.

================================================================================
2. PARTES SEPARADAS (pasta binaries/, gravacao manual com esptool.py)
================================================================================

  ESP12E:
    esptool.py --chip esp8266 --port COMx write_flash 0x0 BrewBOSS_v2.2.26c_esp12e.bin
    esptool.py --chip esp8266 --port COMx write_flash 0x200000 BrewBOSS_v2.2.26c_esp12e_fs.bin

  ESP32-C3:
    esptool.py --chip esp32c3 --port COMx write_flash 0x0 BrewBOSS_v2.2.26c_esp32c3_bootloader.bin
    esptool.py --chip esp32c3 --port COMx write_flash 0x8000 BrewBOSS_v2.2.26c_esp32c3_partitions.bin
    esptool.py --chip esp32c3 --port COMx write_flash 0xe000 BrewBOSS_v2.2.26c_esp32c3_boot_app0.bin
    esptool.py --chip esp32c3 --port COMx write_flash 0x10000 BrewBOSS_v2.2.26c_esp32c3.bin
    esptool.py --chip esp32c3 --port COMx write_flash 0x290000 BrewBOSS_v2.2.26c_esp32c3_fs.bin

  ESP32-C5 (equivalente ao mergeado, porem em partes):
    esptool.py --chip esp32c5 --port COMx --baud 460800 write_flash 0x2000 BrewBOSS_v2.2.26c_esp32c5_bootloader.bin
    esptool.py --chip esp32c5 --port COMx --baud 460800 write_flash 0x8000 BrewBOSS_v2.2.26c_esp32c5_partitions.bin
    esptool.py --chip esp32c5 --port COMx --baud 460800 write_flash 0xe000 BrewBOSS_v2.2.26c_esp32c5_boot_app0.bin
    esptool.py --chip esp32c5 --port COMx --baud 460800 write_flash 0x10000 BrewBOSS_v2.2.26c_esp32c5_app.bin
    (sem arquivo _fs: configs e UI sao criados/embutidos no boot)

================================================================================
3. VERIFICACAO (apos gravar o mergeado, opcional)
================================================================================

  O log do esptool mostra progresso e "Hash of data verified".
  Abra a serial em 115200: deve aparecer o boot do BrewBOSS.
