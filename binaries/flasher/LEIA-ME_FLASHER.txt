================================================================================
                       BREWBOSS WEB FLASHER - BINARIOS
================================================================================
                    SOMENTE USO PESSOAL - NAO COMERCIAL
================================================================================

Esta pasta (binaries/flasher) alimenta o Web Flasher
(https://rampanelli.github.io/BrewBOSS/flasher/). Aqui ficam, por VERSAO do
firmware, dois tipos de imagem por controlador:

  *_full.bin  -> imagem COMPLETA (firmware + filesystem), gravar em 0x000000
                 uma unica vez (1a instalacao ou reset total).
  *_fw.bin    -> SOMENTE firmware (app isolado). Preserva o filesystem
                 (configs, receitas e WiFi) - ideal para atualizar.

O proprio site pergunta qual versao instalar e o modo desejado
("Completo (firmware + filesystem)" ou "Somente firmware (preservar dados)").

Versoes disponiveis (as antigas 2.2.25s e 2.2.26a ficam disponiveis para sempre;
a mais nova - hoje 2.2.26b - e sempre a "ultima"):

  2.2.25s (estavel)
  2.2.26a (estavel)
  2.2.26b (ultima)

As partes SEPARADAS (bootloader, partitions, boot_app0, app, filesystem) para
gravacao manual ficam na pasta binarios (uma nivel acima), identificadas por
modelo e versao, ex: BrewBOSS_v2.2.26b_esp32c3_bootloader.bin.

================================================================================
1. IMAGENS FULL (_full.bin - gravar em 0x000000, uma unica operacao)
================================================================================

  BrewBOSS_v2.2.26b_esp12e_full.bin   -> Wemos D1 Mini / ESP8266 (ESP12E)
  BrewBOSS_v2.2.26b_esp32c3_full.bin  -> ESP32-C3 Super Mini
  BrewBOSS_v2.2.26b_esp32c5_full.bin  -> ESP32-C5 MINI V1.0  (imagem unica)

  ESP12E  (ESP8266):  firmware (incl. bootloader) @ 0x000000
                      filesystem (LittleFS)        @ 0x200000
  ESP32-C3:           bootloader                    @ 0x000000
                      partitions                    @ 0x008000
                      boot_app0 / otadata           @ 0x00E000
                      firmware                      @ 0x010000
                      filesystem (LittleFS)         @ 0x290000
  ESP32-C5:           bootloader                    @ 0x002000
                      partitions                    @ 0x008000
                      boot_app0 / otadata           @ 0x00E000
                      firmware (factory image)      @ 0x010000
                      (sem filesystem separado: a UI e os configs padrao sao
                       criados no primeiro boot pelo proprio firmware)

  Observacoes:
  - O arquivo _full ja inclui TODAS as partes posicionadas nos offsets corretos.
  - Use _full na 1a gravacao ou quando quiser apagar tudo e comecar do zero.

================================================================================
2. IMAGENS SOMENTE FIRMWARE (_fw.bin - preserva os dados do filesystem)
================================================================================

  BrewBOSS_v2.2.26b_esp12e_fw.bin     -> app do ESP8266,  gravar em 0x000000
  BrewBOSS_v2.2.26b_esp32c3_fw.bin    -> app do ESP32-C3, gravar em 0x010000
  (ESP32-C5 usa imagem unica _full - sem modo separado)

  Use este modo para ATUALIZAR a versao do firmware mantendo configs, receitas
  e redes WiFi gravadas no LittleFS. Equivale ao OTA de firmware do painel
  (que tambem preserva o filesystem - rota /rest/ota).

================================================================================
3. VERIFICACAO (apos gravar, opcional)
================================================================================

  O log mostra o progresso e "Hash of data verified". Abra a serial em 115200:
  deve aparecer o boot do BrewBOSS. No modo "somente firmware", confirme que
  suas configs/receitas continuam (rede WiFi salva, sensores etc).
